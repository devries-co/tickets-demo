# Never Forgotten

An Earth made of the names of people who are remembered. A MyGriefGuide project.

Served at `/never-forgotten`. Everything for it lives in this folder; the rest of the repo only mounts it
(`src/react-app/main.tsx`, `src/worker/index.ts`, `wrangler.json`).

## Routes

| Path | What |
| --- | --- |
| `/never-forgotten` | The Earth, search, and "Add a Name" |
| `/never-forgotten/remember/<id>` | A memorial's permanent link. Plays the journey, then shows the card. Served with the name, words and photo already in the HTML for link previews and search engines |
| `/never-forgotten/submission/<token>` | A contributor's private status link |
| `/never-forgotten/admin` | Moderation and administration |
| `?demo=<n>` | Preview with n sample names (also in the footer). Sample names are generated in the browser, labelled on screen, and never stored |
| `?static` | The no-WebGL fallback, for testing |

## Code

- `shared/grid.ts` — where every name lives. Slot number -> permanent place on the sphere, and back.
- `shared/earth.ts` — the Earth colour map (land mask + latitude). `shared/landmask.ts` is generated by `scripts/build-landmask.mjs` from Natural Earth data.
- `app/globe.ts` — the WebGL engine: a whole-planet texture plus a sharper detail layer repainted for whatever the camera is looking at, the journey animation, picking.
- `app/` — the React screens. `worker/` — the API (Hono on D1), schema, and the memorial page with link-preview metadata.

## How names are placed

Each published memorial takes the next slot number, once, forever. A slot's anchor on the sphere never moves.
Names are all drawn at one size, which halves each time a level fills (1,952 names, then 7,808, 31,232, ... up to
about 32 million), so the Earth gets finer as it fills and no two names overlap. Open places are drawn as rows of
dim dots in the Earth's colours; no name is ever invented to fill the picture.

The browser never loads the whole collection: it fetches the first few thousand names (legible from far away)
and, beyond that, only the cells in view.

## Setup in Cloudflare

- The D1 database `never-forgotten` (binding `NF_DB`) is created on deploy. Tables are created on first request.
- **Set a Worker secret `NF_ADMIN_PASSWORD`** to enable `/never-forgotten/admin`. Until then nothing can be approved, so nothing is public.
- Optional secret `NF_MODERATOR_PASSWORD`: a second sign-in that can review but not permanently delete.
- Optional variable `NF_MODERATION=auto`: publish clean submissions immediately. Memorials for children and anything flagged still wait for a person. Default is manual review of everything.

For local development, put `NF_ADMIN_PASSWORD=...` in `.dev.vars` (git-ignored).

## Not built yet

- Email. Contributors get a private status link instead of a notification, and replies to correction requests are sent by hand.
- Photos are stored in D1 (cropped to 512px in the browser). Move them to R2 before the collection grows large.
- Search is prefix matching on a normalised name; switch to full-text search (FTS5) for very large collections.
- Server-rendered overview tiles. Past roughly 125,000 names the far view shows the Earth's colours and occupancy, with names appearing as you zoom in.
